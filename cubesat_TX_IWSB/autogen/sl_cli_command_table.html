CLI Command Reference

info cli_info
MCU ID, Network state, Node ID, PAN ID, Channel ID, etc.
reset cli_reset
Reset the hardware
counter u8 cli_counter
Print out the passed stack counter
Arguments
  • u8Counter type
set_channel u8 cli_set_channel
Set Connect channel
Arguments
  • u8Channel ID
leave cli_leave
Forget the current network and revert to EMBER_NO_NETWORK
set_tx_options u8 cli_set_tx_option
Set Tx options
Arguments
  • u8Security(0x01) MAC Ack(0x02) High Prio(0x04)
start_energy_scan u8 u8 cli_start_energy_scan
Scan the energy level on the given channel
Arguments
  • u8Channel ID
  • u8Number of samples
set_key hex cli_set_security_key
Set security key
Arguments
  • hexSecurity key (size:EMBER_ENCRYPTION_KEY_SIZE)
unset_key cli_unset_security_key
Unset current security key
form u8 [u16] cli_form
Forms a network
Arguments
  • u8Channel
  • u16(optional) Optional PAN ID
set_tx_power i16 [u8] cli_set_tx_power
Sets the antenna output power. The second optional parameter can be used to save the TX power as default
Arguments
  • i16TX power value in 0.1 dBm steps
  • u8(optional) 1 - TX power persistent (saved in token), 0 - TX power volatile
pjoin u8 [str] cli_pjoin
Permit join for a given time period with optional selective payload
Arguments
  • u8Duration
  • str(optional) Optional Join payload
remove_child u8 u16 [hex] cli_remove_child
Remove a specific sensor child from the list
Arguments
  • u8Mode
  • u16Short Address of the child to remove. Not used if long address is given
  • hex(optional) Long Address of the child to remove
meas cli_meas_start
Start one RSSI measurement campaign (frequency-hopping sweep)
meas_stat cli_meas_stat
Print RSSI log status/record count
meas_clear cli_meas_clear
Clear the RSSI log (reset cursor)
meas_auto [u8] cli_meas_auto
Enable/disable periodic auto sweep (arg 0/1; no arg = show state)
Arguments
  • u8(optional) 1=enable periodic sweep, 0=disable
ota_target u8 cli_ota_target
Select OTA target device_id (1-4)
Arguments
  • u8device_id
ota_start u8 cli_ota_start
[TEST-ONLY] Start OTA to device_id without I2C
Arguments
  • u8device_id
slave_list cli_slave_list
Print registered slave list
poll_status cli_poll_status
Force restart polling cycle
iq_start [u16] cli_iq_start
[IQ ground test] Open IQ measurement window for dur_s seconds (replaces OBC 0x05)
Arguments
  • u16(optional) Duration in seconds (default 5)
iq_status cli_iq_status
[IQ ground test] Print queued IQ record count
iq_dump cli_iq_dump
[IQ ground test] Dump all queued IQ records as CSV over UART (replaces OBC 0x06)
